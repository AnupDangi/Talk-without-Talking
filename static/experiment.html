FIELD NOTES

A fair comparison

  1. Keep mic placement and headset fit fixed. Start with still, then jaw open/close and clench controls.
  2. For silent trials, mouth hello, yes, no, water, help without voicing. Repeat each word evenly.
  3. Use whisper and normal speech as acoustic controls. Compare conditions; do not treat a transcript as proof of silent decoding.
  4. Repeat with the Mac's built-in mic and any other input that appears in the inventory.

If a Bluetooth input is missing, reconnect it, enable its microphone/call profile in system audio settings, and refresh. Allow microphone access for the app running this server if the system asks. Headphone output over a cable does not always provide a microphone input.
